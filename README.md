# 點卷棒

給學校老師使用的班級考卷繳交追蹤頁面。純靜態網頁，狀態與設定儲存在該裝置的瀏覽器（localStorage）。

線上版：https://dave851221.github.io/PaperTracker/

## 操作

- **點擊**班級：未繳交 ↔ 已繳交
- **長按**班級：標示／取消「有狀況」
- **設定**（右上角齒輪）
  - 點擊前先確認（預設開啟）
  - 本節免繳：不列入統計，重置時一併清空
  - 停用班級：按鈕直接隱藏，重置不影響
  - 重置全部：燈號回到未繳交，並清空本節免繳

## 開發

無需建置，直接開啟 `index.html` 即可。
